# PRD: 전국 어린이 보호구역 안심 보행 지도 및 경로 추천 서비스

## 1. 프로젝트 개요 (Overview)
- **프로젝트명**: 어린이 보호구역 안심 보행 스마트 지도 (Safe School Zone Navigation & Map)
- **목적**: `전국어린이보호구역표준데이터.csv` 데이터를 기반으로, 어린이 보호구역 데이터의 시각화, 실시간 20m 접근 알림, 조건별 필터링, 그리고 CCTV 밀집도와 넓은 도로폭을 고려한 **스쿨존 중심 최적 안심 보행 경로 탐색 서비스**를 제공한다.
- **주요 사용자**: 어린이, 학부모, 교통안전 관리자, 보행 안전에 관심 있는 일반 시민.

---

## 2. 주요 기능 및 상세 요구사항 (Detailed Requirements)

### 2.1 지도 및 마커 렌더링 (Req-1)
- **기능**: 전국 14,000여 개 어린이 보호구역 위도/경도 좌표 기반 지도 마커 표시.
- **상세 사항**:
  - Leaflet.js / Kakao Maps API 기반의 반응형 인터랙티브 지도 구현.
  - 마커 클러스터링(MarkerCluster)을 도입하여 대용량 데이터 로딩 시 쾌적한 성능 유지.
  - 시설종류(초등학교, 유치원, 어린이집, 특수학교 등)별 직관적인 색상 구분 아이콘/마커 사용.

### 2.2 어린이 보호구역 20m 접근 알림 (Req-2)
- **기능**: 사용자 위치(또는 위치 이동 시뮬레이터)가 어린이 보호구역 경계/중심 좌표 기준 20m 이내로 들어올 경우 알림 발송.
- **상세 사항**:
  - HTML5 Geolocation API를 통한 실시간 위치 추적.
  - Haversine 알고리즘을 사용한 사용자 ↔ 보호구역 정밀 거리 계산.
  - 20m 남았을 때 **비프음/경고 사운드(Web Audio API)** 및 **시각적 Alert/토스트 메세지** 동시 제공.
  - 위치 이동 테스트를 쉽게 검증할 수 있는 '위치 시뮬레이션(마우스 이동/경로 이동)' 기능 포함.

### 2.3 사이드바 조건 필터링 (Req-3)
- **기능**: 사이드바 UI를 통해 사용자가 원하는 어린이 보호구역 범위를 동적으로 필터링.
- **상세 사항**:
  - **지역 필터**: 시/도 및 시/군/구 선택.
  - **시설종류 필터**: 초등학교, 유치원, 어린이집 등 다중 선택.
  - **도로폭 범위 필터**: 최소/최대 보호구역 도로폭(m) 범위 슬라이더.
  - **CCTV 필터**: CCTV 설치 여부(Y/N) 및 최소 CCTV 설치 대수 설정.
  - 필터 변경 시 지도 마커, 클러스터, 사이드바 검색 결과 리스트가 실시간 업데이트.

### 2.4 마커 클릭 상세 팝업 (Req-4)
- **기능**: 지도 상 마커 클릭 시 보호구역 핵심 정보 팝업(Popup) 출력.
- **상세 정보**:
  - **대상시설명** (예: 이천초등학교, 리틀킹어린이집)
  - **주소** (소재지도로명주소 우선, 없을 경우 소재지지번주소)
  - **보호구역도로폭** (예: 6m ~ 12m)
  - **관할경찰서명** (예: 이천경찰서)
  - **추가 정보**: CCTV 설치 여부 및 대수, 관리기관명.

### 2.5 출발지/도착지 길찾기 (Req-5)
- **기능**: 사용자가 출발지와 도착지를 키보드로 직접 입력하거나 지도 상에서 설정하여 경로 검색.
- **상세 사항**:
  - **직접 키보드 입력 및 실시간 자동완성(Autocomplete)**: 시설명, 도로명주소, 지번주소를 입력 시 실시간 추천 목록 출력.
  - **지오코딩 & 미지정 텍스트 위치 자동 변환**: OpenStreetMap Nominatim 지오코딩 API 연동을 통해 사용자가 입력한 자유 주소/장소명을 위치 좌표로 자동 변환.
  - **다양한 입력 방식 지원**: 키보드 직접 입력, 지도 핀 클릭, 보호구역 팝업 버튼, 내 위치 지정 버튼 지원.
  - 출발지/도착지 핀 아이콘 및 경로 라인 지도 렌더링.
  - 경로 총 거리, 예상 도보 소요 시간 계산 및 요약 카드 제공.

### 2.6 CCTV 밀집도 & 넓은 도로폭 중심 스쿨존 최적 보행 경로 추천 (Req-6)
- **기능**: 일반 단순 최단 경로와 달리, **CCTV가 많고 도로폭이 넓은 어린이 보호구역**을 적극 경유하는 안심 보행 경로 추천.
- **상세 알고리즘 & 가중치 모델**:
  - **경로 가중치 (Cost Score)** 계산 Formula:
    $$\text{Cost} = \text{거리(Distance)} \times \left(1 - w_1 \times \text{CCTV 점수} - w_2 \times \text{도로폭 점수}\right)$$
  - CCTV 대수가 많고, 보호구역 도로폭이 넓을수록 가중치 차감(안심 경로선호).
  - **비교 분석**:
    - `일반 경로 (Standard Route)`: 순수 최단 거리 경로.
    - `스쿨존 안심 경로 (Safe Zone Route)`: CCTV 밀집도 및 도로폭 가중치가 반영된 안전 보행 경로.
  - 안심 보행 지수(Safety Rating: ★★★★★) 및 통과 스쿨존 개수 표시.

## 3. UI/UX 디자인 가이드라인

- **레이아웃**:
  - **사이드바 (좌측 360px)**: 검색/필터, 길찾기 탭(출발/도착), 보호구역 목록, 안심 경로 요약 카드.
  - **메인 영역 (우측 전체)**: 지도 Canvas (Leaflet/Custom Map), 플로팅 컨트롤 (내위치, 20m 알림 ON/OFF, 시뮬레이터).
- **디자인 컨셉**: Dark Modern / Glassmorphism 스타일, 직관적인 안심 그린(Emerald Green) & 안전 옐로우(Safety Yellow) 테마 accent color.
- **반응형 지원**: 모바일/데스크톱 모두 지원하는 패널 토글 UI.

## 4. 데이터 구조 및 전처리

- **원본 파일**: `전국어린이보호구역표준데이터.csv` (EUC-KR 텍스트, 14,648건 데이터)
- **전처리 계획**: `make_data_json.js` 스크립트를 작성하여 정제된 JSON (`data/schoolzones.json`) 또는 `data.js` 파일 생성.
- **필드 파싱**:
  - `facility_name` (대상시설명)
  - `facility_type` (시설종류)
  - `address_road` (소재지도로명주소), `address_jibun` (소재지지번주소)
  - `lat` (위도, Float), `lng` (경도, Float)
  - `police` (관할경찰서명)
  - `cctv_yn` (CCTV설치여부), `cctv_count` (CCTV설치대수, Int)
  - `road_width` (보호구역도로폭, Float)

## 5. 성공 기준 & 검증 계획 (Verification Criteria)

1. **마커 표시**: 14,000+ 건의 데이터가 오류 없이 지도 상 마커/클러스터로 렌더링될 것.
2. **20m 접근 알림**: 시뮬레이션/위치 이동 시 20m 진입 시 사운드 및 알림이 100% 정상 발동할 것.
3. **필터링 기능**: 도로폭 슬라이더, CCTV 여부, 지역 필터 적용 시 1초 이내 실시간 마커 및 목록 변경.
4. **팝업 정보**: 팝업 창에 대상시설명, 주소, 도로폭, 관할경찰서가 명확하게 출력될 것.
5. **안심 경로 추천**: 출발지-도착지 지정 시 일반 최단 경로 대비 스쿨존/CCTV/도로폭 우선 경로가 시각적으로 생성 및 안내될 것.
